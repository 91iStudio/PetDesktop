# Пушиши на рабочем столе

Маленький питомец из игры [pet.91i.ru](https://pet.91i.ru) гуляет по панели задач Windows.
Это открытый код приложения: его можно прочитать и собрать самому.

## Что приложение делает

- Показывает питомца поверх панели задач: гуляет, спит, радуется, когда его гладят, его можно перетащить мышкой.
- Раз в 10–15 минут обращается к `pet.91i.ru` — и **только** туда: забрать картинки питомца и отправить события
  («погладили», «провели вместе N часов»).
- Хранит картинки и настройки в `%LOCALAPPDATA%\91iPet`.

## Чего приложение не делает

- Не читает ваши файлы, буфер обмена и список программ.
- Не требует прав администратора и не устанавливается: один exe, удаляется вместе с папкой.
- Не запускается само, пока вы не включите «Автозапуск» в меню.
- Полноэкранную игру или фильм определяет только у себя на компьютере (чтобы спрятаться) и никуда об этом не сообщает.

В меню у часов есть «Что я отправлял» — журнал каждого запроса с содержимым, и «Нагрузка» — сколько приложение
занимает процессора и памяти прямо сейчас.

## Сборка

Код появится здесь по мере разработки. Сборка — одной командой `dotnet publish` (.NET 10, NativeAOT).
